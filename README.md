# 모여봄 HTML 프로토타입

지역·관심사 기반 모임 앱의 설계와 브라우저에서 확인할 수 있는 웹·모바일 HTML 프로토타입입니다. 서비스 이름은 가칭입니다.

공개 화면: [기기 자동 선택](https://giry02.github.io/moa/) · [웹](https://giry02.github.io/moa/web.html) · [모바일](https://giry02.github.io/moa/mobile.html)

배포 경로와 HTML 갱신 방법은 [배포 안내](docs/deployment.md)에서 확인합니다.

## 실행

웹은 `prototype/index.html`, 모바일 화면 검토는 `prototype/mobile.html`에서 시작합니다. 패키지 설치나 빌드가 필요하지 않습니다. HTML·JS·CSS와 `assets` 폴더를 함께 유지하세요.

HTTP로 확인하려면 프로젝트 폴더에서 다음 명령을 실행합니다. 사용 가능한 로컬 포트를 선택해 브라우저를 엽니다.

```powershell
python scripts/preview.py --open
```

웹과 모바일에서 같은 저장 데이터를 확인하려면 위 HTTP 미리보기로 실행하세요. 실행한 주소의 `/mobile.html`로 모바일 화면을 열 수 있습니다. 이전 미리보기 주소 `http://127.0.0.1:7261/`을 다시 쓰려면 `python scripts/preview.py --port 7261 --open`으로 실행합니다.

서버는 실행한 터미널에서 `Ctrl+C`로 종료합니다.

## 수익모델 발표 자료

`prototype/revenue-model.html`을 브라우저에서 열면 14장의 PPT 방식 HTML 발표 자료를 확인할 수 있습니다. 현재 프로토타입을 바탕으로 모임 Pro·개인 Plus·유료 정모 수수료·지역 제휴를 제안합니다. 가격·사용량·매출·비용은 검증 전 가정이며 현재 서비스에 결제가 추가된 것은 아닙니다.

- 방향키·하단 버튼으로 이동하고, `O`로 목차, `F`로 전체화면을 엽니다. 모바일은 가로 스와이프도 지원합니다.
- 9~10장의 입력값을 바꾸면 매출과 직접비·고정 운영비 계산이 함께 갱신됩니다. 보수·기준·확장 시나리오는 비용 가정도 초기화합니다.
- **인쇄 / PDF**로 전체 슬라이드를 인쇄하거나 브라우저에서 PDF로 저장할 수 있습니다.
- 이미지·CSS·JavaScript를 HTML 하나에 포함하므로 파일만 복사해 오프라인에서 열 수 있습니다. 수치 입력은 해당 브라우저의 로컬 저장소에만 저장됩니다.

HTTP 미리보기에서는 `/revenue-model.html`로 엽니다.

## 확인할 흐름

1. 탐색의 **내 근처 / 내 관심사**에서 검색어·지역·관심사로 모임을 찾습니다.
2. 모임을 만들거나 가입한 뒤 홈·게시판·사진첩·정모를 확인합니다. 모임 관리에서 소개·커버 이미지·색상·태그를 바꿉니다.
3. 게시판에 사진과 글을 등록하고 댓글을 남깁니다. 이미지를 넣은 공지를 작성하고 상단에 고정합니다.
4. 세로로 표시되는 멤버 목록에서 사진·이름·역할을 보고 행을 눌러 상세 프로필·작성 글·참여 정모를 확인합니다. 마이에서 사진을 관리하고 대표 썸네일을 선택합니다. 기본 프로필은 가상의 동아시아인 사진 5종입니다.
5. 여러 정모 중 하나에 참석하고 해당 정모의 참석자 전용 대화방에 들어갑니다. 참석을 취소하면 접근이 제한됩니다.
6. 채팅에서 `@`를 입력해 사진·이름 목록에서 멤버를 고릅니다. 말풍선을 오른쪽으로 밀어 답장을 선택하고 원문 카드를 눌러 돌아갑니다. 입력창 아래 이모티콘 패널에서 스티커를 골라 미리 본 뒤 전송하거나 미니 이모티콘을 본문에 넣습니다. 사진·메시지 반응도 확인합니다.
7. 공용방의 쌓인 대화 시연과 요약에서 수백 건의 실제 샘플 원문·안 읽은 수·요약 대상·기간·근거를 확인합니다. 과거 원문에서 최신 대화로 돌아갑니다.
8. 채팅의 나를 멘션하는 시연으로 알림함을 확인하고, 알림에서 해당 방·원문으로 이동합니다. 기본 알림은 멘션만 받도록 설정합니다.
9. 지도 이미지에서 정모의 목적지 핀을 확인하고 외부 지도에서 장소를 엽니다. 새 정모에 장소와 상세 집결 위치를 등록합니다.

모바일 메뉴는 단계별로 표시합니다. 모임 밖에는 탐색·내 모임·채팅·마이, 모임 안에는 홈·게시판·사진첩·정모·채팅이 나타납니다. 채팅에서 뒤로가면 모임 홈으로, 모임에서 뒤로가면 전체 목록으로 돌아갑니다. 모바일 채팅은 공통 헤더와 하단 메뉴 자리를 사용하며 방 선택·알림·시연은 상단 더보기에서 엽니다. 선택한 스티커는 넓은 본문 입력창 위에 남아 있어 글과 함께 전송할 수 있습니다.

모바일 채팅방의 `⋯ → 채팅 글자 크기`에서 대화를 보며 12~22px로 조절합니다. 기본값은 13px이며 설정은 이 브라우저에 저장합니다. 모바일의 채팅 메시지·멘션·답장 원문에만 적용하고 게시판·입력창·데스크톱 크기는 유지합니다. 운영체제나 다른 앱의 글자 크기를 변경하지 않습니다.

## 구현 범위

프로토타입은 샘플 데이터와 브라우저 로컬 상태로 동작합니다. 텍스트 입력과 사진 선택은 브라우저 안에서 처리하며 실제 서버에 업로드하지 않습니다. 게시글·공지·댓글·프로필·모임 커버 사진은 용량을 줄여 브라우저에 저장합니다. 채팅에서 새로 첨부한 사진은 메모리 미리보기이며 새로고침하면 사라집니다.

AI 요약은 수백 건의 샘플 대화의 발췌와 규칙 처리를 이용한 데모이며 실제 모델을 호출하지 않습니다. 지도에는 실제 공개지도에서 준비한 목적지 스크린샷을 표시합니다. 정적 미리보기이므로 실제 GPS 경로를 계산하지 않으며 외부 지도 열기를 제공합니다.

실제 서비스에는 로그인·DB·실시간 채팅 서버·파일 저장소·AI 모델·동적 지도 API·모바일 원격 푸시를 연결해야 합니다. HTML 알림함과 멘션 시연은 동작하지만 실제 APNs/FCM 푸시 전송은 하지 않습니다. 진동은 사용자의 설정과 브라우저·기기 지원 범위를 따릅니다. API 키나 계정 정보는 포함하지 않습니다.

대표 카테고리와 로컬 장소 5개를 이용해 탐색·등록을 시연합니다. 요약 기간은 안 읽은 대화·오늘·최근 7일을 제공합니다. 채팅은 최신 위치로 열고 입장 순간의 안 읽은 범위를 별도로 보존합니다. 승인제 가입은 설정 저장까지 포함하며 다른 사용자의 승인 신청 처리는 구현하지 않습니다.

## 파일

- `docs/product-design.md`: 전체 메뉴, 카테고리, 모임·정모, 채팅·AI, 지도, 데이터·권한, 구현 순서와 수용 기준
- `docs/interaction-design-v2.md`: 정모 대화방, 멘션·답장·알림, 수백 건 요약, 커뮤니티 이미지·프로필 확장 설계
- `prototype/index.html`: 웹 진입점
- `prototype/mobile.html`: 모바일 화면 진입점
- `prototype/styles.css`: 반응형 화면 스타일
- `prototype/app.js`, `chat-enhancements.css`: 정모·채팅·답장·멘션·알림·요약과 화면
- `prototype/community.js`, `community.css`: 이미지 게시판·댓글·공지·모임 관리·프로필·탐색
- `prototype/sticker-packs.js`, `emoji-drawer.css`: 원본 벡터 스티커 팩과 입력창 아래 이모티콘 패널
- `prototype/mobile-chat.css`: 모임 단계별 메뉴·모바일 전체 높이 채팅·본문 위/도구 아래 입력창
- `prototype/chat-font.js`, `chat-font.css`: 모바일 채팅 전용 글자 크기 조절·미리보기·저장
- `prototype/assets`: 로컬 샘플 얼굴·모임 사진·실제 지도 스크린샷과 출처
- `prototype/assets/avatars/PROMPTS.md`: 내장 imagegen으로 생성한 가상 인물 사진 5종의 최종 프롬프트
- `scripts/preview.py`: 선택 사항인 로컬 HTTP 미리보기 실행 도구

지도 API의 지원 범위와 요약 기능 사례는 설계 문서의 공식 출처 링크에서 확인할 수 있습니다.

## 검증

확장판에서 실제 공용방 511개·정모방 120개 대화와 안 읽은 300개 범위, 특정인·기간별 요약 건수·출처, 최신 일정 변경, 답장·멘션·이모지·알림함·정모 참석 권한·대화 연결 게시글을 점검했습니다. 커뮤니티 글·댓글·공지·관리·대표사진 저장과 360px·390px 화면도 확인했습니다.

확장판 결과는 `artifacts/prototype-expanded-chat-qa.json`, `artifacts/prototype-expanded-community-qa.json`, `artifacts/prototype-expanded-final-qa.json`에 기록합니다. 최초 버전의 검증 기록은 `prototype-qa.json`, `prototype-final-qa.json`입니다.

추가 수정의 세로 멤버 목록·가상 인물 사진 전환·기존 대표사진 선택 보존은 `prototype-latest-friends-qa.json`, `prototype-latest-avatar-qa.json`에 기록합니다. 실제 터치의 스와이프 답장·세로 스크롤·사진의 우발적 클릭 방지·방 전환 취소와 웹 드래그는 `prototype-latest-swipe-qa.json`에서 확인합니다.

스티커 선택 후 스와이프 답장의 결합·전송·선택 초기화, 강제 모바일 430px와 360px 넘침 검증은 `prototype-latest-sticker-qa.json`에 기록합니다. 스티커 단독 전송·스티커 원문 답장·새로고침 복원·최근 사용·미니 이모지 입력도 브라우저에서 확인했습니다.

메뉴와 채팅 공간 수정 결과는 `artifacts/prototype-chat-layout-qa.json`에 기록합니다. 390×844 화면에서 대화 영역은 417px에서 619px로 늘었고, 360px·강제430px에서도 입력창 아래 빈 공간과 가로 넘침이 없습니다. 단계별 뒤로가기·정모방 선택·전체 화면 요약·스티커와 글·답장 동시 전송을 확인했습니다.

글자 크기 조절은 `artifacts/prototype-chat-font-qa.json`에서 키보드 조절·실시간 반영·새로고침 복원·기본값·모바일 적용 범위와 360px 최대 글자 크기 넘침을 검증했습니다. `artifacts`는 로컬 검토용 결과이며 Git에는 포함하지 않습니다.

이번 확장판의 새 이미지 파일 선택은 브라우저 파일 접근 제한으로 자동 검증하지 않았습니다. 해당 제한을 우회하지 않았으며, 파일 입력과 이미지 크기·형식·저장 실패 처리는 코드 검토, 포함된 샘플 사진 표시·확대·대표사진 변경은 브라우저에서 확인했습니다.
