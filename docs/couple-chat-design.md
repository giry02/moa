# 두 사람의 대화 화면

사용자가 요청한 인물·관계 설정으로 작성한 프로토타입 대화다. 실제 계정 가입, 실제 대화 수집 또는 실제 관계 확인을 수행한 기록은 아니다. 화면 안에서는 요청대로 샘플 표시를 붙이지 않고 자연스러운 채팅으로 구성한다.

- 이호형은 사용자가 제공한 사진을 프로필로 사용한다. 지수의 기존 사진과 브라우저에서 선택한 대표 사진은 그대로 유지한다.
- 기간은 2026년 9월 14일~10월 25일, 6주다. 대화는 960개로 둘만의 방 840개와 모임방 120개이며, 주요 순간 11개를 원문에 연결했다. 모임 첫 만남부터 서로 알아가는 시간, 첫 데이트, 고백, 모임에 교제 공개, 친구들의 축하와 이후 연애로 이어진다.
- 지수는 표현이 풍부하고 애교 있는 말투, 이호형은 짧은 말과 행동으로 챙겨주는 성격으로 구성한다.
- 두 사람 전용 대화는 `group:couple`에 저장하며 일반 탐색·가입 모임 수·운영 장부·정모 캘린더에는 추가하지 않는다. 현재 대화의 본인은 이호형으로, 일반 모임의 기존 본인 ID와 분리한다.
- 채팅 목록의 두 사람 카드 또는 `mobile.html?room=couple`, `web.html?room=couple`로 들어간다. 상단의 ‘함께한 일상’에서 주요 순간의 원문으로 이동하고, 대화에 보낸 사진을 모아 본다.
- 답장·원문 이동·멘션·반응·스티커·본문 글자 크기는 기존 채팅 동작을 사용한다. 두 사람의 대화는 일반 모임 게시판으로 연결하지 않는다.
- 전체 6주 또는 최근 범위, 특정인의 대화를 요약할 수 있으며 기존 원문 발췌 방식으로 동작한다. 전체 기간에서는 첫 인사·고백과 수락·교제 공개 후의 대화 등 주요 장면을 우선한다. 원문은 현재 방과 선택한 사람의 범위 안에서만 고른다.

신규 대화와 표시 설정은 로컬 브라우저에 저장한다. 기존 모임·정모·게시글·사진 선택과 사용자 메시지는 초기화하지 않는다. 제공한 인물 사진·이름·연애 설정과 대화를 공개 GitHub 및 사이트에 올리는 범위는 사용자 확인을 받았다.
