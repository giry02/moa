# 모여봄 확장 상호작용 설계

수정일: 2026년 10월 26일

기존 모임 탐색·정모·채팅·요약에 참석자 전용 대화방과 이미지 중심 커뮤니티 기능을 더한다. 사용자가 제시한 카카오톡 화면처럼, 멘션은 입력창에서 멤버를 고르는 기능이고 답장은 원문 카드가 붙으며 해당 원문으로 돌아갈 수 있는 기능으로 구체화한다.

## 웹과 모바일

웹 진입 화면은 넓은 탐색 카드·좌측 메뉴·채팅과 요약의 분할 화면을 제공한다. 모바일은 모임 밖에서만 탐색·내 모임·채팅·마이 하단 메뉴를 표시한다. 모임 안에서는 공통 헤더와 하단 메뉴를 숨기고 모임 이름과 홈·게시판·사진첩·정모·채팅 메뉴를 제공한다. 채팅의 뒤로가기는 모임 홈으로, 모임의 뒤로가기는 내 모임 목록(미가입 모임은 탐색)으로 연결한다. 데이터와 기능은 두 화면에서 동일하게 동작하며 별도의 모바일 HTML 진입점을 제공한다. 현재 단계는 브라우저 프로토타입이며 네이티브 앱 배포는 이후다.

모바일 채팅은 화면 전체 높이를 사용한다. 상단에는 뒤로가기·방 이름·AI 요약·더보기를 두고, 방 선택·알림 설정·수신 시연은 더보기로 모은다. 안 읽은 대화가 있을 때만 짧은 요약 배너를 표시한다. 입력창은 본문 영역과 아래 도구 줄로 나누고 전송 버튼을 오른쪽에 둔다. 선택한 스티커는 입력창 위쪽에 미리보기로 유지하며 타이핑이나 키보드 전환으로 삭제하지 않는다. 명시적 취소·전송·방 이동에서 선택을 비운다. 웹도 모임 안에서는 왼쪽 메뉴를 해당 모임의 5개 메뉴로 바꾸고 목록으로 돌아가면 전체 메뉴를 복원한다.

채팅방 더보기의 `채팅 글자 크기`는 실제 대화 위에 작은 조절 바를 연다. 12~22px 슬라이더·실시간 미리보기·기본 13px 복원을 제공하고 현재 읽던 메시지 위치와 작성 상태를 보존한다. 이 기기의 브라우저에 설정을 저장해 모바일의 모든 채팅방에서 같은 크기를 적용한다. 적용 대상은 채팅 메시지·멘션·답장 원문이며 스티커 이미지, 제목·조작 UI, 입력창, 게시판과 데스크톱 크기는 유지한다. 시스템 글자 크기나 브라우저 확대 설정은 변경하지 않는다.

## 모임 탐색

탐색 상단을 `내 근처`와 `내 관심사`로 나눈다. 내 근처는 선택한 활동 지역을, 내 관심사는 저장한 관심사와 검색 조건을 우선 적용한다. 사용자가 말한 “내 항목”은 이 설계에서 내 관심사로 해석한다. 가입한 모임과 찜한 모임은 내 모임에 모은다.

거리와 위치는 실제 GPS를 조회하지 않는 프로토타입에서 정밀한 실측값처럼 표시하지 않는다. 지역 선택·관심사 선택·검색을 함께 적용하고 결과 없음에서 조건을 바꿀 수 있게 한다.

## 여러 정모와 참석자 대화방

한 모임 안에 날짜·장소·인원이 다른 정모를 여러 개 둔다. 정모 목록에서 참석 상태를 확인하고, 카드의 `대화방` 또는 각 정모 상세의 `정모 대화방`으로 들어간다. 참석 신청 전에는 잠금 상태와 참석 안내를 표시한다. 채팅 상단의 방 이름이나 더보기에서 모임 공용방과 정모 참석자방을 선택할 수 있으며, 모임 밖 채팅 목록에서도 정모별 방을 확인한다.

- 공용방은 해당 모임 멤버가 이용한다.
- 정모방은 해당 정모의 참석 신청자만 이용한다. 모임 운영 역할만으로 참석 권한을 대체하지 않는다.
- 참석 취소·모임 탈퇴 시 해당 방 접근과 새 메시지·사진 전송을 즉시 막는다.
- 알림·답장·게시글 연결로 진입할 때도 현재 참석 상태를 다시 검사한다.
- 메시지·사진·읽음 위치·요약·멘션 후보는 방별로 분리한다.

실제 서버에는 `ChatRoom.type = group | meetup`, `group_id`, 선택적인 `event_id`를 둔다. `(event_id, user_id)`의 유효 참석 상태와 모임 가입 상태를 기준으로 요청·실시간 연결·첨부파일·요약 접근을 검사한다. 프로토타입의 로컬 검사는 같은 이용 흐름을 시연한다.

## 멘션 자동완성

입력창에서 `@`를 입력하면 현재 방의 멤버 사진·이름 목록이 입력창 위에 열린다. 뒤에 이름을 입력하면 목록이 좁혀진다. 위·아래 방향키로 이동하고 Enter 또는 터치로 선택하며 Esc로 닫는다. 한글 조합 중 Enter는 전송으로 처리하지 않는다.

선택된 태그는 `mention_user_ids`에 실제 사용자 ID로 저장한다. 단순히 본문에 이름을 적은 경우와 구분하고, 닉네임이 바뀌어도 같은 사람에게 연결한다. 전송 전 삭제한 태그에는 알림을 만들지 않는다. 정모방에는 그 정모의 참석자만 후보로 노출한다.

보낸 메시지에서는 태그가 눈에 띄게 표시되고 누르면 멤버 상세로 이동한다. 다른 사람의 글에 적힌 이름이나 인용문을 멘션으로 추정해 자동 알림하지 않는다.

## 답장과 연결된 게시글

말풍선을 오른쪽으로 밀면 답장 아이콘이 나타나고 일정 거리 이상 민 뒤 놓으면 입력창 위에 원문 작성자·발언 일부·사진 썸네일이 있는 카드가 붙는다. 답장 버튼도 같은 동작을 제공한다. 세로 스크롤·짧은 이동·동작 취소·방 전환은 답장을 선택하지 않는다. 답장 내용을 입력하고 멘션·이모지·사진을 함께 전송할 수 있다. 취소하면 일반 메시지로 돌아간다.

전송된 답장 말풍선 위쪽에는 원문 카드가 붙는다. 카드를 누르면 해당 방의 원문을 불러와 이동·강조하고, 최신 이동 버튼으로 돌아올 수 있다. 이미지 원문이면 작은 사진을 보여준다. 원문이 삭제되었거나 접근할 수 없으면 그 상태를 표시한다.

대화에서 `게시글로 남기기`를 선택하면 게시글 작성 폼에 선택 메시지의 연결 카드가 붙는다. 게시글에는 별도의 제목·본문·이미지를 작성하며, 연결 카드는 `room_id + message_id`로 원문을 찾는다. 정모방의 비공개 대화를 모임 전체 게시판으로 공유할 때는 원문 접근 범위를 확인하고 공개되지 않은 본문을 카드에 노출하지 않아야 한다. 실제 구현은 게시글·원문 양쪽의 접근 권한을 검사한다.

입력창 아래에 이모티콘 패널을 펼친다. `이모티콘 / 미니 이모티콘` 탭과 팩 선택 줄을 제공한다. 토끼 10종·고양이 8종·곰 8종·오리 8종 중 팩을 고르며 최근 사용에서는 팩을 섞어 다시 선택한다. 이모티콘은 선택한 스티커를 미리 보고 전송하며, 미니 이모티콘은 본문에 문자를 넣는다. 원본 벡터 캐릭터를 샘플 팩으로 사용하고 카카오의 캐릭터 이미지는 복제하지 않는다. 스티커 단독 또는 글과 함께 보낸 메시지 모두 일반 라운드 말풍선의 배경·여백을 유지한다. 보낸 스티커는 팩별 ID로 저장하고 답장·원문 연결·확대·새로고침 복원을 지원한다. 메시지 반응은 사용자·메시지·이모지별 중복 없이 토글한다. 특정 이모지와 기능은 아이콘에만 의존하지 않고 접근 가능한 이름을 갖는다.

## 알림과 앱 푸시

기본 대화 알림은 `멘션만`으로 두어 일반 대화는 조용히 받고 나를 멘션한 메시지는 별도의 알림으로 처리한다. 방별 `전체 대화 / 멘션만 / 끄기`와 진동 선호를 제공한다. 이는 채팅방의 일반 알림을 꺼도 멘션을 따로 받을 수 있다는 뜻이다.

앱 안에는 읽음·안 읽음과 대화방을 구분하는 알림함을 둔다. 알림을 누르면 해당 방·메시지로 이동한다. 취소한 정모나 탈퇴한 모임의 알림은 원문 대신 현재 접근 상태를 안내한다. HTML에서는 수신 메시지와 멘션을 시연하는 버튼으로 알림 생성·확인·원문 이동을 검토한다.

실제 앱은 서버가 알림 레코드를 생성하고 Android FCM·iOS APNs로 전송한다. 앱 권한과 운영체제 설정에 따라 알림·진동을 제공하며, 기기 알림 권한을 무시하는 강제 진동으로 구현하지 않는다. [Firebase 알림 권한 안내](https://firebase.google.com/docs/cloud-messaging/android/get-started), [Apple 알림 권한 안내](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications), [Apple 사용자 알림](https://developer.apple.com/documentation/usernotifications)

`Notification`에는 수신자, 발신자, 유형, room_id, message_id, 생성·읽음 시각을 저장한다. 서버는 멘션 대상이 현재 방의 유효 멤버인지 확인하고, 자기 자신·삭제된 태그·중복 재전송에 중복 알림하지 않는다. 앱에서 푸시를 눌렀을 때와 알림함에서 눌렀을 때 같은 경로로 이동한다.

## 수백 건 대화의 요약 검토

공용방에는 수일간 쌓인 실제 샘플 메시지 수백 개를 넣는다. 정모 준비, 시간·장소 제안과 변경·확정, 준비물, 참석 확인, 일상 대화를 섞는다. 정모방에도 별도 대화가 쌓이도록 하며 서로 같은 메시지를 복제한 방으로 만들지 않는다.

안 읽은 배너에는 실제 읽음 위치 이후의 메시지 수를 표시한다. 쌓인 대화를 검토하는 시연 기능은 사용자 작성 데이터를 삭제하지 않고 읽음 범위를 조정한다.

요약 결과에는 선택한 대상·기간, 포함 메시지 수, 생성 시점에 고정한 마지막 메시지, 근거 원문을 표시한다. 특정인 모드는 해당 작성자의 메시지를 먼저 필터링한다. 생성 중 들어온 새 메시지는 다음 생성에 포함한다.

일정·장소는 단순 제안과 확정을 구분하고, 변경이 있으면 최신 확정과 변경 흐름을 보여준다. 결과 항목을 누르면 실제 수백 건 중 해당 원문에 도달해야 한다. 메시지 수만 크게 적고 실제 원문이 없는 시연으로 만들지 않는다. 프로토타입의 규칙 기반 예시 요약과 실제 LLM 호출은 구분한다.

## 이미지 게시판과 공지

게시글 작성에서 제목·분류·본문·여러 이미지를 입력하고 업로드 전 미리보기와 개별 제거를 제공한다. 작성 후 상세 보기·수정·삭제가 가능하며 댓글을 작성하고 댓글 수가 갱신된다. 댓글도 사진을 첨부할 수 있다.

공지 역시 이미지가 있는 게시글로 저장한다. 운영 역할이 공지로 고정하거나 해제하며 홈 화면에서 최신 공지를 확인한다. 글·댓글 작성자 사진과 닉네임을 누르면 프로필로 이동한다.

모임 관리에서는 소개·커버 사진·표현 색상·태그를 바꾼다. 저장한 커버는 모임 카드와 상세에 함께 반영한다. 실제 서비스는 모임장·운영진에게 관리 권한을 주고 일반 글은 작성자와 운영자의 편집 권한을 구분한다.

## 멤버 상세와 사진 관리

채팅·멘션 목록·글·댓글·멤버 목록에서 같은 대표 사진을 사용한다. 이름 글자 대신 로컬에 포함된 가상의 동아시아인 샘플 얼굴 사진을 기본으로 보여준다. 모임 홈의 `함께하는 사람들`은 사진·이름·역할이 있는 세로 목록으로 두며 행 전체를 눌러 프로필을 연다. 프로필에는 소개·사진·현재 모임에서 작성한 게시글·참여 정모를 보여주고 글을 눌러 상세를 연다.

본인 프로필에서 사진을 여러 개 등록하고 대표 썸네일 선택·삭제가 가능하다. 변경 시 채팅과 멘션 후보의 썸네일도 함께 갱신한다. 사진은 모바일에서도 얼굴이 잘 보이도록 원형 또는 일관된 크기의 썸네일로 자른다.

HTML에서 등록한 커뮤니티 사진은 크기를 줄여 브라우저에 저장하고 용량 초과·이미지 로딩 실패를 처리한다. 실제 서비스에서는 비공개 파일 저장소와 서버 권한 검사·썸네일 생성으로 연결한다.

## 목적지가 보이는 지도

정모 상세와 장소 선택에 실제 지도의 정적 스크린샷을 넣고, 대상 장소·목적지와 출처를 표시한다. 좌표·장소명·외부 지도 버튼이 같은 목적지를 가리키도록 확인한다. 화면에는 정적 미리보기임을 표시하고 실제 GPS 경로를 계산한 것처럼 임의 경로선을 그리지 않는다. 동적 지도·도보·대중교통·자동차 경로는 실제 API 연동 단계에서 연결한다.

## 확장 수용 기준

1. 웹·모바일 두 진입점에서 같은 데이터를 조작하고 360px에서 입력·팝업·폼이 넘치지 않는다.
2. 여러 정모에 각각 다른 방이 있고 참석·취소에 따라 접근이 바뀐다.
3. `@`로 사진·이름 후보를 골라 멘션하고, 답장 카드로 실제 원문에 돌아간다.
4. 일반 메시지와 나를 멘션한 메시지가 알림 설정에 따라 다르게 처리된다.
5. 수백 개 실제 샘플 대화의 요약 건수·대상·기간과 원문 근거가 일치한다.
6. 게시글·공지·댓글에 사진을 등록하고 수정·삭제·저장할 수 있다.
7. 모임 커버·꾸미기와 내 대표 사진 변경이 여러 화면에 함께 반영된다.
8. 멤버가 쓴 글과 사진을 상세에서 확인할 수 있다.
9. 내 근처와 내 관심사로 탐색 결과를 구분한다.
10. 지도 스크린샷에 목적지가 보이고 지도 제공자 출처를 유지한다.
11. 실제 터치에서 오른쪽 스와이프로 답장을 선택하고 세로 스크롤과 취소 동작은 유지한다.
12. 이모티콘 패널에서 스티커 선택·미리보기·전송·새로고침 보존·답장 원문 이동이 동작한다.
13. 함께하는 사람들은 모든 화면에서 세로 목록이며 같은 가상 인물 사진이 채팅·태그·프로필에도 표시된다.
