# 모임 편의 기능 확장

수익모델 대화의 운영·개인 편의 제안을 실제로 조작할 수 있는 웹/모바일 프로토타입에 연결했다. 모든 체험은 무료이며 실결제·구독 서버는 연결하지 않는다.

## 진입점

- 탐색의 **전체 일정** 또는 **내 모임 → 통합 캘린더**에서 여러 모임의 정모를 함께 확인한다.
- 내 모임과 마이에 있는 **보관함 · 조건 알림**에서 정모를 저장하고 발견 조건을 관리한다.
- 모임 안의 **모임 운영** 또는 **편의 · 꾸미기 → 운영 도구 열기**에서 반복 정모, 명단과 장부를 관리한다.
- **편의 · 꾸미기**에서 앱 안에 적용되는 채팅 테마와 모집 표시를 체험한다.
- 모바일 채팅방 안에는 앱 하단 메뉴를 표시하지 않는다. 뒤로 가기로 모임 또는 전역 메뉴로 돌아간다.

## 기능과 데이터 기준

| 기능 | 구현 동작 |
|---|---|
| 통합 캘린더 | 월별 달력과 일정 목록, 전체/가입/참석 및 개별 모임 필터, 상세와 참석자 대화방 연결 |
| 일정 충돌 | 내가 참석하는 정모끼리 비교. 종료 시간이 없으면 2시간으로 가정했음을 명시 |
| 캘린더 내보내기 | 참석 정모를 표준 `.ics` 파일로 다운로드. 한국 시간을 UTC로 변환. 외부 계정의 실시간 양방향 동기화는 후속 서버 작업 |
| 보관함 | 정모 북마크, 개인 모음, 가입 모임만 보기, 저장 및 취소 |
| 관심 조건 | 장소 지역·그룹 관심사·한국 요일·시간으로 실제 정모 매칭. 이후 새로 매칭된 정모를 앱 안에서 안내 |
| 반복 정모 | 기존 정모를 바탕으로 주간 일정을 생성. 생성한 정모는 캘린더·상세·참석자방에 연결 |
| 대기 명단 | 참석 정원이 찼을 때 대기를 관리하고 빈자리를 확인해 충원하는 운영 체험 |
| 출석·회비 | 정모 참석자별 출석과 납부 상태, 회비 금액 및 합계, CSV 다운로드. 회비 장부는 결제나 자금 보관 기능이 아님 |
| 모집 분석 | 샘플 지표임을 명시한 운영 화면. 실서비스의 방문·전환 추적은 연결 전 |
| 부스트·강조 | 별도 상단 카드 또는 기존 카드 테두리로 7일 체험. 해당 모임의 지역·관심사 탐색 조건을 따르고 광고/체험을 표시 |
| 꾸미기 | 세 가지 개인 채팅 테마, 기존 4팩 34종 이모티콘과 모임 이미지 꾸미기 연결 |

## 모바일 글자 기준

2026-10-26 네이버 모바일 메인(`https://m.naver.com/`)과 네이버 카페 모바일(`https://m.cafe.naver.com/ca-fe/`)의 실제 메뉴 계산 스타일을 확인했다. 두 화면의 주요 메뉴는 16px였다. 카페 채팅은 로그인으로 이동해 본문 스타일을 직접 측정하지 못했다.

본 앱의 모바일 목록 제목은 17~18px, 본문·주요 메뉴는 16px, 부가 설명은 13~14px, 작은 상태 정보는 12px를 기준으로 삼았다. 모바일 채팅 기본값은 16px이며 기존 12~22px 조절 기능과 명시적으로 저장한 개인 설정은 유지한다. 글자 확대는 이 앱 안에서만 적용된다. 데스크톱 화면에는 모바일 크기 변경을 적용하지 않는다.

## 구현 범위

정모와 참석 여부는 기존 `Moyobom` 상태를 사용한다. 캘린더 보기 설정·회원 도구·운영 장부·테마는 각 확장의 독립된 localStorage 키로 저장하며, 기존 브라우저 데이터를 초기화하지 않는다. 미가입 모임이나 참석하지 않은 정모의 전용 채팅방은 기존 접근 검사를 거친다.

프로토타입은 서버가 없는 단일 브라우저 체험이다. 실서비스에서는 운영자 역할 검증, 대기 순서와 정원에 대한 동시성 제어, 실제 알림/푸시, 예약 공지 작업, QR 체크인 검증, 결제·구독 권한, 외부 캘린더 인증·동기화, 실제 분석 집계, 앨범/PDF와 단체 관리 등을 별도로 연결해야 한다.
