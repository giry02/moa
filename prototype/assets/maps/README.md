# 목적지 지도 미리보기

OpenStreetMap 공개 지도에서 실제 타일과 목적지 마커를 캡처한 PNG입니다. 상단 장소명만 화면에 추가했으며 지도 데이터, 마커 위치, 하단 출처 표시는 보존했습니다.

© OpenStreetMap contributors. 지도 데이터: ODbL 1.0.
https://www.openstreetmap.org/copyright

각 장소의 캡처 URL, 좌표 확인 원문, 주소, 날짜는 ../place-previews.json에 기록되어 있습니다. 정적 목적지 미리보기이며 실시간 교통 및 경로를 나타내지 않습니다.
